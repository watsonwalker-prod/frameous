## The rule

1. Shortlist from `library/review.html` / inbox.  
2. Generate from a **pack** only to fill a hole in the shortlist — a handful, not a hundred.  
3. Human picks.  
4. **Iterate winners only** (`ITERATE.md`). One axis at a time, 3 variants max.  
5. Framed mock (`FRAMED-MOCK.md`) only after the still is a keeper.  
6. Upscale only then. Printful / Shopify create stays **parked**.

Never batch-gen past a shortlist. If you want “20 more like Floral Rifle,” you want **one** iterate axis, three frames, stop.

## House DNA (all packs)

- Light: one directional key — Rembrandt or golden-hour side — never flat.  
- Lens: 35 / 50mm, vertical 2:3 or 4:5, analog grain.  
- Palette: charcoal, cream, brass, olive, ochre, dusty rose.  
- Motifs you may repeat: numeral **7**, eagle/globe *patch*, white ceramic cup, porthole, gold rods, floral rifle.  
- Refuse: plastic skin, neon, watermarks, gibberish text, extra fingers, catalog smile, white-cube studio, Hubble candy, real-brand lockups.
